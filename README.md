# Pedro Emanuel Tech - Portal de Tutoriais

Site oficial de apoio ao canal do YouTube: 👉 [youtube.com/@PedroEmanuelTech](https://www.youtube.com/@PedroEmanuelTech)

---

## 📌 Sobre o Projeto

Este projeto é um portal web voltado para centralizar e organizar os tutoriais publicados no canal **Pedro Emanuel Tech**, com foco em:

- Tecnologia
- Automação
- Scripts práticos
- Ferramentas úteis
- Dicas técnicas aplicáveis no dia a dia

O site foi desenvolvido como ambiente de estudo e treinamento pessoal utilizando IA integrada ao Replit, com objetivo de:

- Aprimorar fluxo de desenvolvimento assistido por IA
- Estruturar projetos modernos
- Integrar com GitHub
- Automatizar deploy com Netlify

---

## 🧠 Tecnologias Utilizadas

- **React**
- **TypeScript**
- Componentização modular
- Hooks personalizados
- **TailwindCSS**
- Lucide Icons
- **Replit** — ambiente de desenvolvimento com IA
- **GitHub** — controle de versão
- **Netlify** — deploy automático

---

## 🎯 Objetivo do Projeto

Este site serve como:

- Hub central dos conteúdos do canal
- Organização de tutoriais em formato blog
- Extensão prática dos vídeos
- Ambiente experimental para uso de IA no desenvolvimento

---

## ⚙️ Requisitos do Sistema

Para rodar localmente:

- Node.js 18+
- npm ou yarn
- Conta no GitHub
- Conta no Netlify (para deploy)

---

## 🚀 Deploy

O projeto está configurado para deploy automático via Netlify:

1. Push no GitHub
2. Netlify detecta alterações
3. Build automático
4. Publicação online
